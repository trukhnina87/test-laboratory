Назначение систем контроля версий

GitHub - крупнейший веб-сервис для хостинга IT-проектов и их совместной
разработки. Веб-сервис основан на системе контроля версий Git.
Ознакомиться с документацией по работе с GitHub можно на сайте GitHub Help.

Зачем система контроля версий нужна в тестировании:
1. Тест-кейсы и чек-листы хранятся рядом с кодом и версионируются вместе с ним.
2. По истории коммитов видно, когда и из-за какого изменения упал тест.
3. Ветви позволяют готовить новый набор проверок, не ломая рабочий.
4. Pull request - это точка, где проверки проходят до попадания в main.
