# Тест-лаборатория

Учебный проект по дисциплине «Инженер по тестированию»: веб-приложение для ведения тест-кейсов, чек-листов и дефектов учебной команды тестирования.

## Назначение репозитория

Здесь хранятся проектная документация, тестовые материалы и вспомогательные скрипты. Управление задачами проекта ведётся в облачной системе Kaiten, версионирование материалов — в этом репозитории.

## Состав ветвей

- **main** — проектная документация, прошедшая проверку;
- **ВтораяВетвь** — скрипты обработки результатов прогона и тестовые данные;
- **ТретьяВетвь** — текстовые материалы: справочные заметки и регламенты.

## Этапы разработки

1. Анализ предметной области и обзор сервисов-аналогов
2. Сбор и формализация требований
3. Проектирование архитектуры и базы данных
4. Прототипирование пользовательского интерфейса
5. Реализация клиентской и серверной части
6. Тестирование веб-приложения
7. Развёртывание на хостинге и сопровождение

## Запуск скрипта отчёта

    python checklist_report.py results.csv

Скрипт читает CSV с результатами прогона и выводит сводку по модулям: сколько проверок пройдено, сколько провалено и какова доля успешных. Если есть проваленные проверки, скрипт завершается с ненулевым кодом возврата — это позволяет использовать его в автоматической сборке.
